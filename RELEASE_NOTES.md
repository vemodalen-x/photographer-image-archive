# Photographer Image Archive 1.0.0

The first stable Windows release provides a local visual research archive for discovering a photographer's public official-site portfolio, reviewing results as they arrive, preserving source metadata, and identifying duplicates.

The portable package includes the Windows application and public documentation only. It contains no sample archive, downloaded photographs, local database, browser state, activity logs, screenshots, or machine-specific paths.

Network destinations are restricted to public addresses, redirects are validated one hop at a time, and dynamic rendering is isolated to the validated official-site host. The package includes the applicable third-party license and notice texts.

The executable is currently unsigned. Windows SmartScreen may therefore request confirmation on first launch. Verify the ZIP against `SHA256SUMS-v1.0.0.txt` before opening it.
